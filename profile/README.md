## KB

This organization holds **KB**, a private knowledge base. You won't see it in the repository list because it is private, not because it is missing. Access is by invitation.

**If a link to KB shows a 404 page:**

1. Sign in to GitHub with the account that was invited.
2. Accept your invitation at https://github.com/Boolean-Beluga/KB/invitations. Invitations expire after 7 days.
3. Open https://github.com/Boolean-Beluga/KB again.

Not invited yet? Ask the person who sent you the link.
