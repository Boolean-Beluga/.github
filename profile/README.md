# Boolean Beluga

An independent, personal research project in mathematics: belief revision and logic, algebra and geometry, and
problems in information theory and communication. It is the work of one person, done in their own time. It is not
affiliated with, or endorsed by, any employer, university or other organization, and it does not represent anyone's
views but the author's.

## Repositories

KB (private, by invitation) holds the project's released documents and code:

- the definitions document: the definitions and notation every other document cites;
- background material: earlier work the project builds on;
- kbpoly: a dependency-free Python package for conditional knowledge bases, studied with methods from algebraic
  statistics: it computes, exactly, their polynomials, Newton polytopes, consistency registers and subdivisions.

Everything in KB is a working snapshot: careful, but not peer reviewed, and it may contain errors. Other repositories
may be added here later; each will say what it holds.
